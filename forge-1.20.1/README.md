# Tab Tweaks

Forge 1.20.1. Меняет иконки вкладок креатива и переставляет их по страницам и слотам.

Настройка прописывается в `config/tabtweaks.toml`, появляется после первого захода в игру.

Пример:

```
[[tab]]
id   = "efbosses:bosses" (название вкладки)
page = 2 (страница вкладки, на которую переносим)
slot = 3 (номер слота, на который хотим поставить)

[[tab]]
id   = "minecraft:combat" (название вкладки)
icon = "pob_equipment:blood_sea_katana" (id предмета, чья иконка будет нарисована)

[[tab]]
id     = "chipped:chipped_tab" (название вкладки)
hidden = true (сделать вкладку невидимой)
```

Всё это пишется в один и тот же файл, друг за другом. Отдельных конфигов на вкладку не нужно!

### Дополнительно:

Расположение слотов на странице:

```
 1  2  3  4  5      верхний ряд
[предметы креатива]
 6  7  8  9 10      нижний ряд
```

Команды:

* `/tabtweaks list` — чтобы узнать id всех вкладок
* `/tabtweaks reload` — перечитать конфиг, чтобы он применился после F3+T
